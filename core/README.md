# @j5g3/core 
	
[![npm version](https://badge.fury.io/js/%40j5g3%2Fcore.svg)](https://badge.fury.io/js/%40j5g3%2Fcore)

A work-in-progress graphics engine built with TypeScript, leveraging WebGPU

## Project Details

-   Branch Version: [0.0.1](https://npmjs.com/package/@j5g3/core/v/0.0.1)
-   License: GPL-3.0
-   Documentation: [Link](https:/github.com/j5g3/engine/core)
-   Report Issues: [Github](https://github.com/j5g3/engine/issues)

## Installation

	npm install @j5g3/core

Key features include:

-   Uses WebGPU API for high-performance GPU rendering.
-   Instanced rendering with dynamic per-instance model matrices and colors.
-   Shader-based transformations and texture sampling using WGSL.
-   Efficient management of GPU buffers and resources.
-   Designed in TypeScript with strong typing.

Visit the [demo](https://j5g3.github.io/engine/demo/) to see the engine in action.
